# 示例详情

通过 URL query `?ex=示例id` 选择示例（默认 `init`），支持四框架变体 Tab、iframe 实时预览与源码查看。

- 示例 id 列表：`init` / `layer-visibility` / `pbf-layer` / `viewport-zoom` / `marker-clean` / `popup` / `use-map-events` / `geo-tools`
- token 读取顺序：URL `?token=` → `localStorage.MINEMAP_TOKEN`；切换 Tab 时保留当前示例与 token 状态。
