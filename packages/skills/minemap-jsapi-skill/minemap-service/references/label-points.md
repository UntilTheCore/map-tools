# 求多边形标注点

描述：根据一个或多个多边形坐标点集合分析多边形标注点。

## 接口介绍

| 项           | 值                                                                                                |
| ------------ | ------------------------------------------------------------------------------------------------- |
| 接口地址     | http://ip:port/tianjing-server/function-api/services/geometryUtilities/GeometryServer/labelPoints |
| 请求方式     | GET                                                                                               |
| 请求数据类型 | application/json                                                                                  |
| 响应类型     | application/json                                                                                  |

## 参数说明

| 参数     | 类型   | 说明                    | 必填 | 默认 |
| -------- | ------ | ----------------------- | ---- | ---- |
| polygons | array  | 多边形数组              | 是   |      |
| sr       | array  | 图形坐标系              | 否   |      |
| f        | string | 接口输出格式(html/json) | 否   |      |
| key      | string | 服务鉴权使用的 key      | 是   |      |

## 数据返回格式

| 字段        | 类型  | 说明       |
| ----------- | ----- | ---------- |
| labelPoints | array | 标注点坐标 |

## 服务样例

| 参数     | 值                                                                                                                                                                                                                                                                              | 备注                 | 必填 |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------- | ---- |
| polygons | [{"rings":[[[1.1972718691415412E7,3374198.2506193877], [1.1972759845986621E7,3374364.0344391097], [1.1972636570583798E7,3374459.1335052033], [1.197245817827938E7,3374526.1245190296], [1.1972321053873042E7,3374634.7850046842], [1.1972718691415412E7,3374198.2506193877]]]}] | 一个或多个多边形数组 | 是   |
| f        | json                                                                                                                                                                                                                                                                            | 返回格式             | 是   |

接口返回示例

````json
{
    "TiantuMapServerVersion": "3.0",
    "labelPoints": [
        {
            "x": 11972611.287572883,
            "y": 3374411.5839721565
        }
    ]
}```
````

## 注意事项与已知文档问题

- 返回 `labelPoints` 为多边形标注点坐标数组。
