# 裁切或者延伸线几何

描述：根据目标线图形裁剪或者延伸至目标线图形。 更新：2023-04-20

## 接口介绍

| 项           | 值                                                                                                                                                           |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 接口地址     | http://ip:port/tianjing-server/function-api/services/geometryUtilities/GeometryServer/trimExtend?polylines={polylines}&trimExtendTo={trimExtendTo}&key={key} |
| 请求方式     | GET                                                                                                                                                          |
| 请求数据类型 | application/json                                                                                                                                             |
| 响应类型     | application/json                                                                                                                                             |

## 参数说明

| 参数         | 类型   | 说明                     | 必填 | 默认 |
| ------------ | ------ | ------------------------ | ---- | ---- |
| polylines    | array  | 目标线图形               | 是   |      |
| trimExtendTo | object | 截断或者延伸至目标线图形 | 是   |      |
| f            | string | 接口输出格式(html/json)  | 否   |      |
| key          | string | 服务鉴权使用 key         | 是   |      |

## 数据返回格式

| 字段       | 类型  | 说明                 |
| ---------- | ----- | -------------------- |
| geometries | array | 裁切或者延伸几何图形 |

## 服务样例

| 参数         | 值                                                                                                   | 备注                     | 必填 |
| ------------ | ---------------------------------------------------------------------------------------------------- | ------------------------ | ---- |
| polylines    | [{"paths":[[[1.1972718691415412E7,3374198.2506193877], [1.1972759845986621E7,3374364.0344391097]]]}] | 目标线图形               | 是   |
| trimExtendTo | {"paths":[[[1.1972759845986621E7,3374364.0344391097], [1.1972636570583798E7,3374459.1335052033]]]}   | 截断或者延伸至目标线图形 | 是   |
| f            | json                                                                                                 | 接口输出格式(html/json)  | 否   |

接口返回示例：

```json
{
  "geometries": [
    {
      "paths": [
        [
          [11972718.691415412, 3374198.2506193877],
          [11972759.845986621, 3374364.0344391097]
        ]
      ]
    }
  ],
  "TiantuMapServerVersion": "3.0"
}
```

## 注意事项与已知文档问题

- 文档中接口地址在 `&key=` 前多了一个空格（原文 `trimExtendTo={trimExtendTo} &key={key}`），此处已去掉。
- `trimExtendTo` 为目标线几何，用于截断或延伸 `polylines`。
