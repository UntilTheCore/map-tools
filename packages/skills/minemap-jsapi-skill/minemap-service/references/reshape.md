# 重塑几何

描述：根据目标图形和重塑图形重塑几何。 更新：2023-04-20

## 接口介绍

| 项           | 值                                                                                                                                          |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 接口地址     | http://ip:port/tianjing-server/function-api/services/geometryUtilities/GeometryServer/reshape?target={target}&reshaper={reshaper}&key={key} |
| 请求方式     | GET                                                                                                                                         |
| 请求数据类型 | application/json                                                                                                                            |
| 响应类型     | application/json                                                                                                                            |

## 参数说明

| 参数     | 类型   | 说明                    | 必填 | 默认 |
| -------- | ------ | ----------------------- | ---- | ---- |
| target   | array  | 目标图形                | 是   |      |
| reshaper | object | 重塑图形                | 是   |      |
| f        | string | 接口输出格式(html/json) | 否   |      |
| key      | string | 服务鉴权使用 key        | 是   |      |

## 数据返回格式

| 字段         | 类型   | 说明     |
| ------------ | ------ | -------- |
| geometry     | object | 几何图形 |
| geometryType | string | 几何类型 |
