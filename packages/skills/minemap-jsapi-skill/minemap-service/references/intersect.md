# 叠置计算

描述：根据目标图形和源图形进行叠置计算。 更新：2023-04-20

## 接口介绍

| 项           | 值                                                                                                                                                    |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| 接口地址     | http://ip:port/tianjing-server/function-api/services/geometryUtilities/GeometryServer/intersect?geometries={geometries}&geometry={geometry}&key={key} |
| 请求方式     | GET                                                                                                                                                   |
| 请求数据类型 | application/json                                                                                                                                      |
| 响应类型     | application/json                                                                                                                                      |

## 参数说明

| 参数       | 类型   | 说明                    | 必填 | 默认 |
| ---------- | ------ | ----------------------- | ---- | ---- |
| geometries | array  | 目标图形                |      |      |
| geometry   | object | 叠置源图形              |      |      |
| f          | string | 接口输出格式(html/json) | 否   |      |
| key        | string | 服务鉴权使用 key        | 是   |      |

## 数据返回格式

| 字段       | 类型  | 说明         |
| ---------- | ----- | ------------ |
| geometries | array | 几何重叠图形 |

## 服务样例

| 参数       | 值                                                                                                                                                                                                                                                                              | 备注                    | 必填 |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------- | ---- |
| geometries | [{"rings":[[[1.1972718691415412E7,3374198.2506193877], [1.1972759845986621E7,3374364.0344391097], [1.1972636570583798E7,3374459.1335052033], [1.197245817827938E7,3374526.1245190296], [1.1972321053873042E7,3374634.7850046842], [1.1972718691415412E7,3374198.2506193877]]]}] | 目标图形                | 是   |
| geometry   | {"paths":[[[1.1972718691415412E7,3374198.2506193877], [1.1972759845986621E7,3374364.0344391097]]]}                                                                                                                                                                              | 叠置源图形              | 是   |
| f          | json                                                                                                                                                                                                                                                                            | 接口输出格式(html/json) | 否   |

## 注意事项与已知文档问题
