# 多边形面积和周长计算

描述：根据一个或多个多边形坐标点集合计算面积和周长。

## 接口介绍

| 项           | 值                                                                                                    |
| ------------ | ----------------------------------------------------------------------------------------------------- |
| 接口地址     | http://ip:port/tianjing-server/function-api/services/geometryUtilities/GeometryServer/areasAndLengths |
| 请求方式     | Get                                                                                                   |
| 请求数据类型 | application/json                                                                                      |
| 响应类型     | application/json                                                                                      |

## 参数说明

| 参数     | 类型   | 说明                     | 必填 | 默认 |
| -------- | ------ | ------------------------ | ---- | ---- |
| polygons | array  | 多边形数组               | 是   |      |
| sr       | array  | 图形坐标系               | 否   |      |
| f        | string | 接口输出格式 (html/json) | 否   |      |
| key      | string | 服务鉴权使用的 key       | 是   |      |

## 数据返回格式

| 字段    | 类型   | 说明 |
| ------- | ------ | ---- |
| lengths | double | 长度 |
| areas   | double | 面积 |

## 服务样例

| 参数     | 值                                                                                                                                                                                                                                                                                | 备注               | 必填 |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------ | ---- |
| polygons | [{"rings":[[ [1.1972718691415412E7,3374198.2506193877], [1.1972759845986621E7,3374364.0344391097], [1.1972636570583798E7,3374459.1335052033], [1.197245817827938E7,3374526.1245190296], [1.1972321053873042E7,3374634.7850046842], [1.1972718691415412E7,3374198.2506193877] ]]}] | 个或多个多边形数组 | 是   |
| f        | json                                                                                                                                                                                                                                                                              | 返回格式           | 否   |

接口返回示例：

```json
{
  "lengths": [1282.513032927214],
  "TiantuMapServerVersion": "3.0",
  "areas": [41020.49991225483]
}
```

## 注意事项与已知文档问题

- 样例表首列表头文档写作「参数值」，与其它页的「参数名」不一致。
- `sr` 不传时按服务端默认坐标系计算，面积单位随坐标系而定。
