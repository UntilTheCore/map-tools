# 驾车路径规划（driving route）

## 接口介绍

| 项       | 值                                                                      |
| -------- | ----------------------------------------------------------------------- |
| 接口地址 | http(s)://ip:port/tianjing-server/lbs-api/route/v2/driving              |
| 请求方式 | GET、POST                                                               |
| 服务描述 | 通过起终点及途经点，避让区域等信息， 针对不同策略，规划出最优行驶路线。 |

## 参数说明

| 参数          | 类型   | 位置           | 说明                                                                                                                                                                                               |
| ------------- | ------ | -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| origin        | string | URL 或表单参数 | 起点，经度在前，纬度在后，经度和纬度用“,”分割。必填。                                                                                                                                              |
| heading       | int    | URL 或表单参数 | 定位方向。起点的车头方向。 取值范围：0-359。可选。                                                                                                                                                 |
| destination   | string | URL 或表单参数 | 终点，经度在前，纬度在后，经度和纬度用“,”分割. 必填。                                                                                                                                              |
| avoidpolygons | string | URL 或表单参数 | 避让区域，支持 32 个避让区域，每个区域最多可有 16 个顶点。经度和纬度用“,”分割，经度在前，纬度在后，坐标点之间用“;”分隔，区域之间用“\|”分隔。如果是四边形则有四个坐标点，如果是五边形则有五个坐标点 |
| avoidpoints   | string | URL 或表单参数 | 避让点，避让点用 lng,lat<中心坐标>;radius<半径/米>表达,多个避让点之间以英文竖线“\|”分割。最大数目：32 个避让点，半径最大支持 5 千米                                                                |
| waypoints     | string | URL 或表单参数 | 途经点，经度和纬度用“,”分割，经度在前，纬度在后，坐标点之间用“;”分隔。最大数目：50 个坐标点。如果输入多个途径点，则按照用户输入的顺序进行路径规划                                                  |
| strategy      | int    | URL 或表单参数 | 算路策略：0：默认; 2：不走高速;4：少收费;5：躲避拥堵                                                                                                                                               |
| ferry         | int    | URL 或表单参数 | 是否走轮渡，0：使用渡轮(默认) ;1：不使用渡轮                                                                                                                                                       |
| alternatives  | int    | URL 或表单参数 | 是否返回备选路线。可选值：0：返回 1 条路线（默认）；1：返回 1-3 条路线                                                                                                                             |
| cartype       | int    | URL 或表单参数 | 车辆类型（影响限行规则），取值：0：普通汽车(默认)；1：新能源；2：插电混动车                                                                                                                        |
| plate_number  | string | URL 或表单参数 | 车牌号，填入车牌信息，包括所在省份，字母需大写。用于判断限行相关。支持 6 位传统车牌和 7 位新能源车牌                                                                                               |
| linkinfo      | int    | URL 或表单参数 | 是否返回 link 详情，包括 linkid、车速等信息；0：不返回（默认）；1：返回                                                                                                                            |
| key           | string | URL 或表单参数 | 开发者应用密钥，必选                                                                                                                                                                               |

## 注意事项与已知文档问题

- `strategy` 参数表只列了 0/2/4/5，返回说明中另有 1/6/7/8/9/10；参数表取值不全。
- `avoidpoints` 为 `lng,lat;radius` 形式，多点间用 `|` 分隔，最多 32 个、半径最大 5km。
- `routeLine` 与 `steps[].polyline` 均为 WKT 字符串，需自行解析成坐标数组。
