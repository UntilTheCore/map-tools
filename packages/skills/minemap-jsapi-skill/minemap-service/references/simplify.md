# 简化几何

描述：根据传入的目标图形简化几何。 更新：2023-04-20

## 接口介绍

| 项           | 值                                                                                                                                                             |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 接口地址     | http://ip:port/tianjing-server/function-api/services/geometryUtilities/GeometryServer/simplify?geometries={geometries}&sr={sr}&tolerance={tolerance}&key={key} |
| 请求方式     | GET                                                                                                                                                            |
| 请求数据类型 | application/json                                                                                                                                               |
| 响应类型     | application/json                                                                                                                                               |

## 参数说明

| 参数       | 类型   | 说明                    | 必填 | 默认 |
| ---------- | ------ | ----------------------- | ---- | ---- |
| geometries | array  | 目标图形                | 是   |      |
| sr         | array  | 坐标系                  | 否   |      |
| tolerance  | number | 容差                    | 否   |      |
| f          | string | 接口输出格式(html/json) | 否   |      |
| key        | string | 服务鉴权使用 key        | 是   |      |

## 数据返回格式

| 字段       | 类型  | 说明         |
| ---------- | ----- | ------------ |
| geometries | array | 简化几何图形 |

## 服务样例

| 参数       | 值                                                                                                                                                                                         | 备注                    | 必填 |

| geometries | [{"rings":[[[1.1972718691415412E7,3374198.2506193877], [1.1972759845986621E7,3374364.0344391097], [1.1972321053873042E7,3374634.7850046842], [1.1972718691415412E7,3374198.2506193877]]]}] | 目标图形                | 是   |
| sr         |                                                                                                                                                                                            | 坐标系                  | 否   |
| tolerance  |                                                                                                                                                                                            | 容差                    | 否   |
| f          |                                                                                                                                                                                            | 接口输出格式(html/json) | 否   |

## 注意事项与已知文档问题

- `tolerance` 容差越大简化越强；不传时由服务端决定默认容差。
