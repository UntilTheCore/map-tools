# 几何断言

描述：根据图标坐标判断断言空间关系。 更新：2023-04-20

## 接口介绍

| 项           | 值                                                                                                                                                                                         |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 接口地址     | http://ip:port/tianjing-server/function-api/services/geometryUtilities/GeometryServer/relation?geometries1={geometries1}&geometries2={geometries2}&relationParam={relationParam}&key={key} |
| 请求方式     | GET                                                                                                                                                                                        |
| 请求数据类型 | application/json                                                                                                                                                                           |
| 响应类型     | application/json                                                                                                                                                                           |

## 参数说明

| 参数          | 类型   | 说明                    | 必填 | 默认 |
| ------------- | ------ | ----------------------- | ---- | ---- |
| geometries1   | array  | 图形 1                  | 是   |      |
| geometries2   | array  | 图形 2                  | 是   |      |
| relation      | string | 断言空间关系            | 是   |      |
| relationParam | String | 断言空间关系类型        | 是   |      |
| sr            | string | 图形坐标系              | 否   |      |
| f             | string | 接口输出格式(html/json) | 否   |      |
| key           | string | 服务鉴权使用 key        | 是   |      |

## 数据返回格式

| 字段      | 类型   | 说明     |
| --------- | ------ | -------- |
| relations | object | 断言关系 |

接口返回示例：

```json
{
  "TiantuMapServerVersion": "3.0",
  "relations": [
    {
      "geometry2Index": 0,
      "geometry1Index": 0
    }
  ]
}
```

## 注意事项与已知文档问题

- 接口地址示例漏写了 `relation={relation}` 参数，实际需要传断言关系。
- `relationParam` 为断言关系的补充参数，随 `relation` 取值不同而不同。
