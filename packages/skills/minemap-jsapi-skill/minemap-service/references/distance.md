# 求距离

描述：以度、弧度、英里或公里为单位计算两点之间的距离

更新：2023-04-20

## 接口介绍

| 项           | 值                                                                                                                                                           |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 接口地址     | http://ip:port/tianjing-server/function-api/services/geometryUtilities/GeometryServer/distance?geometry1={geometry1}&geometry2={geometry2}&sr={sr}&key={key} |
| 请求方式     | GET                                                                                                                                                          |
| 请求数据类型 | application/json                                                                                                                                             |
| 响应类型     | application/json                                                                                                                                             |

## 参数说明

| 参数      | 类型   | 说明                    | 必填 | 默认 |
| --------- | ------ | ----------------------- | ---- | ---- |
| geometry1 | object | 起始点坐标              | 是   |      |
| geometry2 | object | 终止点坐标              | 是   |      |
| sr        | array  | 图形坐标系              | 否   |      |
| f         | string | 接口输出格式(html/json) | 否   |      |
| key       | string | 服务鉴权使用的 key      | 是   |      |

## 数据返回样式

| 字段     | 类型   | 说明 |
| -------- | ------ | ---- |
| Distance | double |      |

## 服务样例

| 参数      | 值                                                 | 备注       | 必填 |
| --------- | -------------------------------------------------- | ---------- | ---- |
| geometry1 | {"x":1.2134705668160098E7,"y":3215439. 4753681566} | 起始点坐标 | 是   |
| geometry2 | {"x":1.2134211253773687E7,"y":3215605. 819201891}  | 终止点坐标 | 是   |
| f         | json                                               | 返回格式   | 否   |

接口返回样例：

```json
{
  "distance": 521.647252950553,
  "TiantuMapServerVersion": "3.0"
}
```

## 注意事项与已知文档问题

- 文档中接口地址含空格（原文 `distance?geo metry1={geometry1}&...&sr={ sr}`），此处已去掉空格，修正为 `geometry1={geometry1}` 与 `sr={sr}`。
- 返回字段 `Distance` 首字母大写，与其它接口的小写字段风格不一致。
