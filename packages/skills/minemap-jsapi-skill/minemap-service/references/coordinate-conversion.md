# 坐标转换服务

将一个坐标系中的坐标转换为另一个坐标系中的坐标的服务，如投影坐标和地理坐标之间的转换。

## 接口介绍

| 项           | 值                                                                                            |
| ------------ | --------------------------------------------------------------------------------------------- |
| 接口地址     | http://ip:port/tianjing-server/function-api/services/geometryUtilities/GeometryServer/project |
| 请求方式     | GET                                                                                           |
| 请求数据类型 | application/json                                                                              |
| 响应类型     | application/json                                                                              |

## 参数说明

| 参数       | 类型   | 说明                    | 必填 | 默认 |
| ---------- | ------ | ----------------------- | ---- | ---- |
| inSR       | string | wgs84                   | 是   |      |
| outSR      | string | 墨卡托投影              | 是   |      |
| geometries | array  | 点/线/面坐标系          | 是   |      |
| f          | string | 接口输出格式(html/json) | 是   |      |
| key        | string | 服务鉴权使用的 key      | 是   |      |

## 数据返回格式

| 字段       | 类型   | 说明           |
| ---------- | ------ | -------------- |
| geometries | object | 转换后的坐标系 |

## 服务样例

| 参数       | 值                                                  | 备注           | 必填 |
| ---------- | --------------------------------------------------- | -------------- | ---- |
| inSR       | 3857                                                | wgs84          | 是   |
| outSR      | 4326                                                | 墨卡托投影     | 是   |
| geometries | [{"x":1.2134705668160098E7,"y":3215439.4753681566}] | 点/线/面坐标系 | 是   |
| f          | json                                                | 返回格式       | 否   |

接口返回示例：

```json
{
  "geometries": [
    {
      "x": 109.00791570000005,
      "y": 27.733689870000024
    }
  ],
  "TiantuMapServerVersion": "3.0"
}
```

## 注意事项与已知文档问题

- 参数表中 `inSR`/`outSR` 的“描述”列写的是取值示例（wgs84 / 墨卡托投影），不是字段含义；示例中实际传 `3857`/`4326`。
- 本页与「坐标投影」页接口地址相同（均为 `project`），可视为同一能力的两处文档。
