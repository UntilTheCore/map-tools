# 缓冲区计算

描述：根据图形坐标及缓存距离计算缓冲区 更新：2023-04-20

## 接口介绍

| 项           | 值                                                                                                                                                                                                                     |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 接口地址     | http://ip:port/tianjing-server/function-api/services/geometryUtilities/GeometryServer/buffer?geometries={geometries}&inSR={inSR}&outSR={outSR}&distances={distances}&unit={unit}&unionResults={unionResults}&key={key} |
| 请求方式     | GET                                                                                                                                                                                                                    |
| 请求数据类型 | application/json                                                                                                                                                                                                       |
| 响应类型     | application/json                                                                                                                                                                                                       |

## 参数说明

| 参数         | 类型   | 说明                    | 必填 | 默认  |
| ------------ | ------ | ----------------------- | ---- | ----- |
| geometries   | array  | 图形                    | 是   |       |
| inSR         | array  | 图形坐标系              | 否   |       |
| outSR        | array  | 输出图形坐标系          | 否   |       |
| distances    | double | 缓冲距离                | 是   |       |
| unit         | string | 缓冲距离单位            | 否   |       |
| unionResults | bool   | 是否合并缓冲区          | 是   | false |
| f            | string | 接口输出格式(html/json) | 否   |       |
| key          | string | 服务鉴权使用 key        | 是   |       |

## 数据返回格式

| 字段       | 类型  | 说明           |
| ---------- | ----- | -------------- |
| geometries | array | 缓冲区坐标集合 |

## 注意事项与已知文档问题

- `unit` 取值文档未列举，常用米（Meters）/度（DecimalDegrees），需按服务端支持传值。
- `geometries` 为 Esri 几何数组（`rings` / `paths` / `points`）。
