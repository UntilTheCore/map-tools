# 闭包计算

描述：通过传入图形进行闭包计算。 更新：2023-04-20

## 接口介绍

| 项           | 值                                                                                                                                 |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| 接口地址     | http://ip:port/tianjing-server/function-api/services/geometryUtilities/GeometryServer/convexHull?geometries={geometries}&key={key} |
| 请求方式     | GET                                                                                                                                |
| 请求数据类型 | application/json                                                                                                                   |
| 响应类型     | application/json                                                                                                                   |

## 参数说明

| 参数       | 类型   | 说明                    | 必填 | 默认 |
| ---------- | ------ | ----------------------- | ---- | ---- |
| geometries | array  | 图形                    | 是   |      |
| f          | string | 接口输出格式(html/json) | 否   |      |
| key        | string | 服务鉴权使用 key        | 是   |      |

## 数据返回格式

| 字段         | 类型   | 说明     |
| ------------ | ------ | -------- |
| geometry     | object | 图形     |
| geometryType | string | 图形类型 |

## 服务样例

| 参数       | 值                                                                                                                                                                                         | 备注     | 必填 |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------- | ---- |
| geometries | [{"rings":[[[1.1972718691415412E7,3374198.2506193877], [1.1972759845986621E7,3374364.0344391097], [1.1972321053873042E7,3374634.7850046842], [1.1972718691415412E7,3374198.2506193877]]]}] | 图形     | 是   |
| f          | json                                                                                                                                                                                       | 返回格式 | 是   |

接口返回示例：

```json
{
  "TiantuMapServerVersion": "3.0",
  "geometry": {
    "rings": [
      [
        [11972718.691415412, 3374198.2506193877],
        [11972321.053873042, 3374634.7850046842],
        [11972759.845986621, 3374364.0344391097],
        [11972718.691415412, 3374198.2506193877]
      ]
    ]
  },
  "geometryType": "esriGeometryPolygon"
}
```

## 注意事项与已知文档问题

- 输入为几何数组，输出凸包多边形。
