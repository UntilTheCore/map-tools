# 坐标投影

描述：根据目标图形分析坐标投影。 更新：2023-04-20

## 接口介绍

| 项           | 值                                                                                                                                                        |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 接口地址     | http://ip:port/tianjing-server/function-api/services/geometryUtilities/GeometryServer/project?geometries={geometries}&inSR={inSR}&outSR={outSR}&key={key} |
| 请求方式     | GET                                                                                                                                                       |
| 请求数据类型 | application/json                                                                                                                                          |
| 响应类型     | application/json                                                                                                                                          |

## 参数说明

| 参数       | 类型   | 说明                    | 必填 | 默认 |
| ---------- | ------ | ----------------------- | ---- | ---- |
| geometries | array  | 目标图形                | 是   |      |
| inSR       | array  | 输入坐标系              | 否   |      |
| outSR      | array  | 目标坐标系              | 否   |      |
| f          | string | 接口输出格式(html/json) | 否   |      |
| key        | string | 服务鉴权使用 key        | 是   |      |

## 数据返回格式

| 字段       | 类型  | 说明     |
| ---------- | ----- | -------- |
| geometries | array | 投影图形 |

## 数据返回格式

| 参数       | 值                                                                                                                                                                                         | 备注                    | 必填 |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------- | ---- |
| geometries | [{"rings":[[[1.1972718691415412E7,3374198.2506193877], [1.1972759845986621E7,3374364.0344391097], [1.1972321053873042E7,3374634.7850046842], [1.1972718691415412E7,3374198.2506193877]]]}] | 目标图形                | 是   |
| inSR       | [1.1972636570583798E7,3374459.1335052033]                                                                                                                                                  | 输入坐标系              |      |
| outSR      | [1.1972636570583798E7,3374459.1335052033]                                                                                                                                                  | 目标坐标系              | 是   |
| f          | json                                                                                                                                                                                       | 接口输出格式(html/json) | 否   |
