# 线段长度计算

描述：根据线图形几何数组计算线段长度。

## 接口介绍

| 项           | 值                                                                                            |
| ------------ | --------------------------------------------------------------------------------------------- |
| 接口地址     | http://ip:port/tianjing-server/function-api/services/geometryUtilities/GeometryServer/lengths |
| 请求方式     | GET                                                                                           |
| 请求数据类型 | application/json                                                                              |
| 响应类型     | application/json                                                                              |

## 参数说明

| 参数      | 类型   | 说明                       | 必填 | 默认 |
| --------- | ------ | -------------------------- | ---- | ---- |
| polylines | array  | 线图形几何数组             | 是   |      |
| sr        | array  | 图形坐标系                 | 否   | sr   |
| f         | string | 接口输出格式（html\|json） | 否   | f    |
| key       | string | 服务鉴权使用的 key         | 是   |      |

## 数据返回格式

| 字段    | 类型   | 说明 |
| ------- | ------ | ---- |
| lengths | double | 长度 |

## 服务样例

| 参数      | 值                                                                                                                                                                                                                                                                                | 备注         | 必填 |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------ | ---- |
| polylines | [{"rings":[[ [1.1972718691415412E7,3374198.2506193877], [1.1972759845986621E7,3374364.0344391097], [1.1972636570583798E7,3374459.1335052033], [1.197245817827938E7,3374526.1245190296], [1.1972321053873042E7,3374634.7850046842], [1.1972718691415412E7,3374198.2506193877] ]]}} | 线图形几何数 | 是   |

接口返回示例：

```json
{
  "lengths": [1282.513032927214]
}
```

## 注意事项与已知文档问题

- 参数表「默认值」列在文档中被误填为参数名本身（`sr`、`f`），并非真实默认值。
