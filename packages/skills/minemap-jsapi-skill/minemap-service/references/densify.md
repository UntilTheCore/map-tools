# 致密几何

描述：根据图形和最大线段长度进行致密集合分析 更新：2023-04-20

## 接口介绍

| 项           | 值                                                                                                                                                                  |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 接口地址     | http://ip:port/tianjing-server/function-api/services/geometryUtilities/GeometryServer/densify?geometries={geometries}&maxSegmentLength={maxSegmentLength}&key={key} |
| 请求方式     | GET                                                                                                                                                                 |
| 请求数据类型 | application/json                                                                                                                                                    |
| 响应类型     | application/json                                                                                                                                                    |

## 参数说明

| 参数             | 类型   | 说明                    | 必填 | 默认 |
| ---------------- | ------ | ----------------------- | ---- | ---- |
| geometries       | array  | 图形                    | 是   |      |
| maxSegmentLength | double | 最大线段长度            | 是   |      |
| f                | string | 接口输出格式(html/json) | 否   |      |
| key              | string | 服务鉴权使用 key        | 是   |      |

## 数据返回格式

| 字段       | 类型  | 说明         |
| ---------- | ----- | ------------ |
| geometries | array | 坐标图标集合 |
